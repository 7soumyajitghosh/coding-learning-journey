💻 Coding Learning Journey

«Learning to code, one program at a time. 🚀»

Welcome to my Coding Learning Journey repository.

This is my personal coding-learning archive where I practice programming, experiment with different languages, understand programming fundamentals, make mistakes, debug them, and gradually improve my coding skills.

This repository is not about showing perfect code.

It is about documenting the journey from beginner to developer.

🟢 First Programs

The "Firstcode" directory contains some of my first programs written while starting my programming journey.

The purpose of these programs is to understand the basic structure and syntax of different programming languages.

---

📖 Chapter 1

The "ch1" directory contains the next stage of my practice.

It includes programs written in multiple languages so that I can understand how similar programming concepts are implemented differently.

One of the goals is to understand the logic behind programming, rather than memorizing the syntax of only one language.

🧠 Learning Approach

My learning process is simple:

Learn
  ↓
Understand
  ↓
Write Code
  ↓
Make Mistakes
  ↓
Debug
  ↓
Fix
  ↓
Practice
  ↓
Build

I believe that making mistakes is an important part of learning programming.

A compiler error is not a failure.

It is information that helps me understand the code better.
